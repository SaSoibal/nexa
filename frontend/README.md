# NEXA — Public Marketplace Frontend Template

Static production-grade UI prototype based on the supplied NEXA income-ecosystem concept.

## 22 pages
Home, Explore, Services, Service Details, Earn, Job Details, Provider Profile,
User Dashboard, My Jobs, My Services, Chat, Wallet, Checkout, Learning,
Course Details, Learning Progress, Profile & Settings, Verification,
Trust & Safety, How It Works, FAQ, Contact.

## Stack
HTML5 + CSS3 + Vanilla JavaScript. No backend dependency.

## Included
Responsive public marketplace, smart matching UI, service/job marketplace,
provider profiles, trust/verification, chat, wallet, checkout, learning,
modals, filters, mobile responsive layouts, BDT/Dhaka demo data.

## Next integration
Connect the UI to Laravel/Vue/React APIs, authentication, RBAC, bKash/card
payments, real-time chat, maps/geolocation, route matching, PUDO QR/OTP,
notifications and admin analytics.
